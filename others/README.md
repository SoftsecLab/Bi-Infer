# Bi-Infer Baseline Methods

This repository provides implementations of seven baseline methods used for comparison with Bi-Infer in machine-generated text origin detection.

The implementations are adapted for the experimental settings of our study.

## 1. Baseline Methods

| Method | Description |
|--------|-------------|
| LRR | Detects machine-generated text using the relationship between token log-likelihood and log-rank. |
| Binoculars | Uses two language models to measure statistical differences through cross-entropy-based scoring. |
| GhostBuster | Extracts statistical features from surrogate language models and trains a supervised classifier. |
| SeqXGPT | Uses token-level probability features and a sequence classification network for source identification. |
| GPT-Who | Extracts statistical features from language model predictions for text origin classification. |
| Sniffer | Analyzes probability-based differences across multiple language models to identify text sources. |
| PROFILER | Extracts contextual probability features and uses a random forest classifier for origin detection. |

LRR, Binoculars, and GhostBuster are evaluated using a source-wise One-vs-Rest (OvR) strategy. The remaining methods use multiclass classification with document-level Macro-F1 evaluation.

## 2. Installation

Python 3.10 or later is recommended.

Install the required dependencies:

```bash
pip install -r requirements.txt
```

A CUDA-enabled GPU is recommended for model inference and training.

## 3. Dataset Format

Training and testing datasets use JSON files organized by source labels.

Example:

```json
{
  "human": [
    "Example human-written text."
  ],
  "generator_a": [
    "Example text generated by model A."
  ],
  "generator_b": [
    "Example text generated by model B."
  ]
}
```

All available classes and valid samples are included without per-class sampling limits.

## 4. Usage

### Run a Single Method

```bash
python run_exp.py \
    --method ghostbuster \
    --task my_dataset \
    --train data/train.json \
    --test data/test.json \
    --models /path/to/model_A /path/to/model_B \
    --output outputs/ghostbuster \
    --gpu 0
```

Available methods:

- `lrr`
- `binoculars`
- `ghostbuster`
- `seqxgpt`
- `gpt_who`
- `sniffer`
- `profiler`

To run another method, change the `--method` argument.

### Run All Methods

```bash
python run_exp.py \
    --method all \
    --task my_dataset \
    --train data/train.json \
    --test data/test.json \
    --models /path/to/model_A /path/to/model_B \
    --output outputs \
    --gpu 0
```

Each method runs independently, and its results are saved in the corresponding output directory.

### Command-Line Arguments

| Argument | Description |
|----------|-------------|
| `--method` | Baseline method to execute, or `all` for all methods. |
| `--task` | Name of the experimental task. |
| `--train` | Path to the training dataset. |
| `--test` | Path to the testing dataset. |
| `--models` | Local model paths or Hugging Face model identifiers. |
| `--output` | Directory for saving experimental outputs. |
| `--gpu` | GPU device index. |
